# Ascension

Appli de remise en forme gamifiée, à usage personnel (PWA pour iPhone).

- `npm install` : installer les dépendances
- `npm run dev` : lancer l'appli en local
- `npm test` : lancer les tests des calculs
- `npm run build` : produire la version en ligne dans `dist/`

La mise en ligne est automatique à chaque envoi sur la branche `main` (GitHub Pages).
Les données restent sur le téléphone (IndexedDB). Ne remplace pas un avis médical.
